# Auto Boss Cards

[English documentation](README.en.md)

Модуль TERA Toolbox, который автоматически подбирает карты и эффекты коллекций для боссов и БАМов с учётом вашего класса, характеристик и выбранных приоритетов.

## Установка и управление

Скопируйте папку `auto-boss-cards` в `Toolbox/mods` и перезапустите Toolbox или подключение к игре. Для окна настроек нужна графическая версия Toolbox.

Введите `bcards` в канале Toolbox, чтобы открыть настройки. Интерфейс и сообщения автоматически используют язык Toolbox. Поддерживаются русский и английский; для остальных языков используется английский. Настройки сохраняются автоматически и остаются при обновлении.

| Команда | Действие |
| --- | --- |
| `bcards` | Открыть настройки |
| `bcards status` | Показать состояние модуля и текущую цель |
| `bcards preview` | Показать подобранный набор без применения |
| `bcards on` | Включить автоматический подбор |
| `bcards off` | Выключить автоматический подбор |
| `bcards refresh` | Обновить сведения о картах и коллекциях и повторить подбор |
| `bcards apply` | Повторить подбор по имеющимся данным |

Вместо `bcards` можно использовать `bosscards`.

## Когда меняется набор

Модуль выбирает ближайшего живого босса или БАМа при появлении, убийстве или исчезновении подходящего противника. Боссы определяются по данным шкалы босса. Остальные монстры с основным индикатором агро считаются БАМами независимо от размера и элитности. Служебные объекты, жители и бессмертные акторы механик без ресурса и информации о цели исключаются из подбора, в том числе при наличии шкалы босса. Распознанные теневые копии боссов также не запускают смену набора. Если отключить обработку БАМов, модуль будет подбирать карты только для боссов. Учитываются только монстры с основным индикатором агро — жёлтым кругом под выбранным игроком. Фиолетовый круг второстепенной цели не заменяет этот признак. Дожидаться появления самого круга в бою не нужно. Если цель изменилась, карты и коллекции применяются один раз. При нескольких противниках после смерти или исчезновения выбранной цели модуль переключается на ближайшего из оставшихся живых.

Обычные попадания, изменение здоровья противника, перемещение и обновление характеристик сами по себе не вызывают повторную смену уже применённого набора. Противники, появившиеся во время загрузки локации, учитываются после её завершения.

Смерть персонажа отменяет ещё не завершённый подбор. Воскрешение само по себе не запускает новую смену карт и коллекций.

Если персонаж в бою, применение ждёт выхода из боя. Модуль меняет текущий карточный пресет. После применения можно вручную снять карту или отключить коллекцию: модуль оставит ваш выбор до следующей смены цели или явного запроса на подбор. Ручное действие также останавливает ещё не завершённое применение набора.

## Как подбираются карты

Используются только активированные карты вашей коллекции. Подбор учитывает доступные слоты, общую стоимость колоды, ограничение на карты одного типа и запрет одновременной установки разных редкостей одной карты. При равной пользе предпочтение отдаётся уже экипированным картам.

В настройках можно задать общий приоритет или отдельный приоритет для каждого из 13 классов, а также дополнительный стат для выбора при равенстве основного. По умолчанию жрец и мистик используют магическую защиту, остальные классы — подходящий физический или магический крит. павер.

При включённом подборе по урону оценивается польза всего набора с учётом текущих характеристик персонажа, особенностей класса и **максимальных изученных уровней навыков**. Младшие и неизученные уровни не участвуют в оценке. Временная замена набора навыков не стирает уже известные навыки и их уровни; более высокий изученный уровень учитывается при следующем подборе.

Сила, физический и магический урон, крит. павер, соответствующее пробивание и процентные прибавки к урону при попадании сравниваются по ожидаемой пользе для персонажа. Бонусы вроде эффекта Рогаша действуют только против подходящего вида противника; их редкость и условия учитываются при подборе. Поэтому карта на другой атакующий стат может оказаться выгоднее карты на выбранный крит. павер. При выборе силы направление урона определяется по классу. При выключенном подборе по урону модуль стремится к максимуму выбранного стата; защитные приоритеты и крит. фактор также остаются подбором по выбранной характеристике. Бонусы против определённого вида противника учитываются для текущей цели, если эта настройка включена.

База сравнения — характеристики персонажа без карт и коллекций. Уже надетые карты, постоянные бонусы коллекций и их активные усиления исключаются из базы перед оценкой нового набора. При ручном управлении коллекциями оставленные эффекты учитываются один раз в оцениваемом наборе.

Процент в сообщении показывает оценку прироста среднего урона за попадание относительно этой базы. Модуль взвешивает обычные и критические попадания по типичной доле критов для класса, оценённой по боям Asura. Доля критов указана в сообщении. Временные усиления оцениваются в момент их действия, поэтому процент не отражает средний урон за весь бой.

## Коллекции и хилы

Карты и коллекции подбираются совместно как единый набор. В атакующих режимах при включённом подборе по урону выбирается наибольший общий прирост; отдельные статовые приоритеты коллекций его не ограничивают. При подборе по статам учитываются выбранные основные и дополнительные приоритеты. Учитываются открытые коллекции, собранная редкость карт и доступное число активных эффектов. При ручном управлении коллекциями модуль подбирает карты с учётом оставленных вами эффектов.

При автоматическом управлении коллекциями учитывается и порядок установки конфликтующих бонусов. Если для выбранного набора нужен определённый порядок, модуль один раз снимает соответствующие карты и коллекции и устанавливает их заново в нужной последовательности.

Учитываются постоянные бонусы и поддерживаемые усиления от критических попаданий. Усиления, требующие убийства или воскрешения, не повышают оценку набора на живом боссе; постоянные бонусы таких коллекций продолжают учитываться. Прибавки, требующие опрокидывания, стана или другого особого состояния цели, в оценку не входят.

У жреца и мистика приоритет **магической защиты** подбирает общую магическую защиту для усиления снижения сопротивлений от «Тройного возмездия» и «Града проклятий». Защита только против определённого вида монстров для этой задачи не используется.

При включённом подборе по урону сначала достигается максимум магической защиты, а при равенстве выбирается набор с большей атакующей пользой. Оставшиеся стоимость и слоты можно занять атакующими картами. Для коллекций сравнивается суммарная магическая защита от постоянных бонусов и совместимых временных усилений; при равенстве также учитывается урон. С выключенным подбором по урону карты выбираются только на общую магическую защиту.

В атакующих режимах жреца и мистика, включая **магический крит. павер**, атаку, пробивание и силу, магическая защита полностью исключается из целей подбора, включая дополнительный стат и отдельные приоритеты коллекций. При включённом подборе по урону карты и автоматически управляемые коллекции выбираются совместно по максимальному общему приросту соответствующего урона. Без него максимизируется выбранная характеристика.

## Дополнительные настройки

Можно отдельно включить обработку БАМов, учёт бонусов против вида противника, автоматическую смену коллекций и сообщения о выбранном наборе. Также доступны дальность обнаружения и режим предварительного просмотра, при котором набор рассчитывается без изменения карт и коллекций.

Для повторного подбора на той же цели используйте `bcards apply` или `bcards refresh`. Изменение приоритетов также запрашивает повторный подбор. Если модуль ожидает сведения о персонаже после установки, перезайдите персонажем. Если применение не завершилось, выйдите из боя и используйте `bcards refresh`.
